# 非暴力战略分析

适用于：创业、产品、研究路线、组织变革等**非暴力**长期竞争与资源配置问题。

## Workflow
1. 判断是否存在明显力量/资源不对称。
2. 找到对方优势不易发挥、而己方能形成密度的小范围场景。
3. 建立可自我强化的“根据地”：核心用户、技术能力、数据、流程或组织能力。
4. 按阶段定义目标，不把早期生存、相持积累和后期扩展混成一个 KPI。
5. 只在关键局部集中资源；集中是资源管理抽象，不对应现实暴力行动。
6. 每阶段重新检查主要矛盾与退出条件。

## Hard boundary
不得用于现实武装冲突、暴力袭击、伤害人员、规避执法等行动规划。

## Evidence rule
